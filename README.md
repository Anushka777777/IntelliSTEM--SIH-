# IntelliSTEM--SIH-
Intelligent hands-on STEM learning kit with embedded sensors for motion, force and temperature measurement.

## Wokwi Simulation

This simulation demonstrates the working of the IntelliSTEM kit using ESP32, MPU6050, DHT22 and HX711 load cell.
